### 2.1d Schema versions and migrations — `src/universe_builder/migrations/`

Stored atoms carry a `schema_version`. `store.write_atom` stamps it on the way
out and `store.read_atom` migrates an older payload forward on the way in, so a
model change does not require rewriting the corpus. Sync create, fix, verify and
expand all use the stamped model path; `commit_fix` accepts a model for this purpose.

Migrations are pure functions on **dicts**, never on models, and run *before*
validation — the entire point is that an old payload may not validate against the
current model. Each declares its atom type and the version it moves from and to;
they are registered with a decorator and discovered by walking the package, so
adding one is dropping in a file. The chain per atom type is validated: gaps,
duplicate source versions and version-skipping steps fail loudly rather than
silently doing nothing. Discovery distinguishes an absent optional migrations
package from a missing dependency *inside* it. Nested import errors propagate;
only a completed import/walk enters `_loaded_sources`. A separate in-progress
set prevents reentrancy without poisoning subsequent retries.

**Version 0 is the default, not an error.** Files that predate the stamp carry no
`schema_version` key at all; they read correctly as version 0 and are left
untouched on disk until a pass rewrites them (a rewrite stamps the current
version).

Two traps worth knowing:

- **Sentinels are never stamped.** `EmptyModel` sets `extra = "forbid"` and
  `store.is_empty_model` validates with `strict=True`, so a stamped
  sentinel stops being recognised as one — and the augment pass uses that check
  to skip empty files, so it would start sending them to the model for repair.
- **`atom_type_of` normalises the filename first.** An `_ERROR` name has no
  `.json` tail for the parser, and `final_city_….json` would otherwise key on the
  atom type `final_city`, which has no chain and would skip migration silently.
  `append_city` genuinely has no chain — `CityAppend` is a different shape and
  must not receive city migrations.
